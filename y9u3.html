    Complete notes
    Python Next Steps revision notes
    The topics follow your five teaching lessons. Use these worked examples to understand the method, then use the Code Lab with different values.
    

    Lesson 1 · Reading code, types, casting and selection
    Python stores values in variables. Common data types are string (text), integer (whole number) and float (decimal number). input() produces text even when digits are typed.
    label = "Workshop"      # a string
visitors = int(input("How many visitors? "))
charge = float(input("Entry price? "))
print(label, visitors * charge)
    Casting converts data types: int("4") becomes 4, float("2.5") becomes 2.5 and str(8) becomes "8". Joining two strings with + joins the text, not the quantities.
    if visitors >= 12:
    print("Group booking")
elif visitors >= 5:
    print("Small group")
else:
    print("Individual booking")
    Selection follows the first true branch. Operators include ==, !=, <, >, <= and >=. Blocks need colons and consistent indentation.
    

    Lesson 2 · For loops and while loops
    A for loop is ideal when repeating a known number of times or visiting each item. range(start, stop, step) includes the start but not the stop.
    for number in range(2, 9, 2):
    print(number)  # 2, 4, 6, 8
    A while loop repeats while its condition is true. Ensure the loop's state can change, or it may continue indefinitely.
    level = 0
while level < 4:
    level = level + 1
    print(level)
    Count iterations carefully. A loop checking count < 4 does not necessarily run four times unless the counter starts and changes as expected. Test 0, 1 and several iterations.
    

    Lesson 3 · Lists, indexes, append and loops
    Lists organise several values together and can grow or change. The first item has index zero.
    temperatures = [12, 15, 13]
print(temperatures[0])  # 12
temperatures[1] = 16    # replace the second item
temperatures.append(14) # add a new item
for temperature in temperatures:
    print(temperature)
    Indexing a position that doesn't exist causes an IndexError. A list is often more efficient than dozens of separate variables.
    

    Lesson 4 · Procedures, definitions, calls and parameters
    In Python, a function can act as a procedure that performs an action when called. Parameters make the same code useful for different inputs.
    def print_ticket(event):
    print("Ticket for", event)

print_ticket("Science fair")
print_ticket("Art club")
    Here, event is a parameter and each supplied event name is an argument. Using functions removes repeated code and makes changes easier.
    

    Lesson 5 · Functions that return values
    Some functions do more than display information: they return a value for the calling programme to use.
    def calculate_discount(price):
    return price * 0.9

sale_price = calculate_discount(30)
print(sale_price)  # 27.0
    return sends a value back and ends that function call. Printing is not the same as returning. Store the value and then use it in another calculation or test.
    def is_large(total):
    return total >= 25

print(is_large(27))  # True
    

    Assessment readiness · Reading, testing and debugging
    For every short programme, explain what each line does, track the values of variables and predict the output before you run it. Practise selecting test values that cover a normal input, a boundary and an invalid input.
    Syntax error: Python cannot interpret the code, for example a missing colon. Logic error: the code runs but gives the wrong result. Runtime error: a problem occurs during execution, such as using an out-of-range list index.
    # Boundary example for an entry limit of 20

    Revision tip: write down what you expect, run the code and explain any difference. That is stronger practice than copying a model solution.
