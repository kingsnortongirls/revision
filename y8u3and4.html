Full revision notes

1. Binary place value

Computers use binary (base 2), made from 0s and 1s. Read place values from right to left: 1, 2, 4, 8, 16, 32, 64, 128. Each step to the left doubles in value.

Place value: 128 64 32 16 8 4 2 1
Binary: 0 1 0 1 0 1 0 0
Value: 64 + 16 + 4 = 84

To convert denary to binary, select the place values that make the target number. For example, 38 = 32 + 4 + 2, so its eight-bit representation is 00100110.

2. Hexadecimal (base 16)

Hex uses the symbols 0–9 and A–F, where A=10, B=11, C=12, D=13, E=14 and F=15. Every hex digit matches a group of exactly four binary digits.

Binary: 0110 | 1101
Hex: 6 | D → 6D₁₆
Denary: 6 × 16 + 13 = 109

To go from binary to hex, group binary digits into fours from the right, adding leading zeros if needed. To convert hex to denary, multiply the left digit by 16 and add the right digit, for a two-digit hex number.

3. Adding binary and dealing with carries

Start at the rightmost column and work left. Remember 1 + 1 = 10₂ and 1 + 1 + 1 = 11₂. Put the rightmost bit in your answer and carry the leftmost bit into the next column.

0110 (6)
+ 0011 (3)
────
1001 (9)

In this example there is no overflow because 9 fits in four bits.

4. Binary shifts and overflow

A logical left shift moves every bit to the left and fills empty places with zero. Provided no significant bits are lost, shifting left once doubles an unsigned number. A logical right shift moves bits right, fills from the left with zeros, and divides by 2, discarding any remainder.

00110100₂ = 52
Left shift 1 → 01101000₂ = 104
Right shift 2 → 00001101₂ = 13

Overflow occurs when a calculation needs more bits than are available. An unsigned four-bit number can hold only 0–15. For example, 14 + 5 = 19, which needs five bits. If stored in four bits, the high bit is lost and the remaining four bits show 3. This is why the bit width matters.

5. Instruction set design

An instruction set describes the operations a machine understands. Each operation can be identified using an opcode. With n bits, there are 2ⁿ different bit patterns. For example, six bits allow 64 distinct opcode patterns and seven bits allow 128.

The maximum number of different instructions that can be represented is not the same as the number of instructions that fit into a programme or memory. The instruction-set activity above demonstrates this distinction.

6. How to earn marks when showing working

  • Binary to denary: write the place values and mark which ones you added.
  • Denary to binary: show how the target is built from powers of two.
  • Denary to hex: show the division by 16 and the remainder.
  • Binary to hex: split into four-bit groups and convert each one.
  • Binary addition: show carries above the columns as you add.
  • Shifts and overflow: state the original value, the direction, number of places and what happened to any discarded bits.
  • Instruction sets: write 2ⁿ and calculate the number of different patterns.
Common mistakes to avoid
  • Reading binary place values in the wrong direction.
  • Thinking hexadecimal letters start at A=11 (A actually means 10).
  • Missing a carry in a column.
  • Assuming a left shift always doubles a number in limited-width storage.
  • Confusing number of distinct opcodes with memory storage capacity.
