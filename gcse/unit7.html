Useful SQL
SELECT Title, Genre FROM Books
WHERE Pages >= 250 AND Available = 'Yes'
ORDER BY Title ASC
The PowerPoints use LIKE 'H*', an Access-style pattern. Standard SQL normally uses LIKE 'H%'. This teaching playground recognises both forms. Use * after SELECT for all fields.
Supported: SELECT, FROM, WHERE, AND, OR, NOT, comparisons, BETWEEN, LIKE, parentheses and ORDER BY. Other statements are deliberately refused.
