Unit 4 · Topic 1
1. Regular polygons & exterior angles
A polygon is a closed shape with straight sides. A regular polygon has equal-length sides and equal interior angles.
When a turtle travels along each side and turns to follow the next side, it uses an exterior (turning) angle. All these turns together make one full rotation.
Exterior angle = 360° ÷ number of sides
Hexagon6 sides · 60°
Nonagon9 sides · 40°
Decagon10 sides · 36°
Dodecagon12 sides · 30°
Worked example
A regular decagon has 10 equal sides.
360° ÷ 10 = 36°. The turtle turns 36° after every side.
Working backwards
A turtle turns 30° each time.
360° ÷ 30° = 12 sides.
Avoid a common error: 360° is for the exterior turns around the whole shape. Do not confuse them with the interior angles inside the polygon.


Unit 4 · Topic 2
2. Discovering number patterns
A sequence is a list of values that follow a rule. You may need to find missing numbers or explain how the pattern works.
TypeDifferent worked exampleHow to continue
Constant addition6, 13, 20, 27…Add 7. Next 34.
Constant subtraction90, 79, 68, 57…Subtract 11. Next 46.
Multiplication2, 6, 18, 54…Multiply by 3. Next 162.
Growing differences3, 7, 13, 21, 31…Gaps +4, +6, +8, +10. Next +12 = 43.
Method: First check the gap between each pair. If it is not constant, try multiplication or look for a pattern in the gaps themselves. Check your rule against every given value before using it.


Unit 4 · Topic 3
3. Efficient drawing algorithms
An algorithm is an ordered set of instructions for a task. You can draw regular polygons efficiently with a loop rather than writing the same move and turn over and over.
Less efficient
MOVE 70
TURN 72°
MOVE 70
TURN 72°
… repeat the same two lines
This repeats instructions by hand, so it is harder to edit.
More efficient
REPEAT 5 TIMES:
    MOVE 70 STEPS
    TURN RIGHT 72°
A short loop can draw a regular pentagon.
The repeat count determines how many sides are drawn, the turn angle determines the direction after each side, and move distance controls the size.
Check an algorithm: For a regular polygon, the repeat count × the exterior turn should equal 360°.


Unit 4 · Topic 4
4. Coordinates & computational thinking
Coordinates (x, y)
x gives the horizontal position. Bigger x usually moves right.
y gives the vertical position. Bigger y usually moves up.
Example: (4, 2) means right 4, up 2 from the origin.
Four key terms
Algorithm: precise steps in the correct order.
Decomposition: splitting a big problem into smaller tasks.
Iteration: repeating instructions.
Abstraction: focusing on useful details while ignoring what is unnecessary.
For an animated scene, decomposition might involve separate procedures for the background, each character and the sound. Abstraction might mean using a simple icon for a complex real-world object.


Unit 4 · Topic 5
5. Predicting Scratch drawings
In Scratch, programs run from top to bottom. Nested blocks inside a loop run repeatedly. The pen draws only when it is down.
Look for these instructions
🟨 When clicked: starts a program.
🟦 Move: changes position.
🟦 Turn: changes direction.
🟩 Pen down / up: controls visible lines.
🟧 Repeat: runs a group of instructions more than once.
Original practice example
when green flag clicked
pen down
repeat (10)
    move (36) steps
    turn clockwise (36) degrees
10 equal movements and turns of 36° make a regular decagon.
To trace a more complicated script, mark the starting point and direction. Work through every move and turn in order. If a pen command is absent, check whether the pen is already up or down.


Unit 4 · Topic 6
6. Python turtle shape code
Python turtle can draw regular polygons with a version of the circle() command that takes a steps argument.
circle(65, steps=10)  # regular 10-sided shape
The first number is the radius, which affects the size. The steps value is the number of straight sides.
You can also use a loop:
for side in range(5):
    forward(70)
    right(72)
This makes a regular five-sided shape. You do not need to memorise a different entire program for every polygon: use the rule 360° ÷ sides.
Exam tip: If asked to adapt existing code, keep its structure and change the value that controls the sides or turn. Do not change unrelated parts.

Choose who is best suited to a task by thinking about safety, speed, accuracy, judgement, feelings and creativity. Sometimes humans and computers work together.
Robots / computers often help with…Humans are particularly important for…

Remember: These are not strict rules. A machine may support a creative task, and a person may supervise a robot. Good answers explain why the choice is suitable, rather than just naming an option.


Unit 5 · Topic 8
8. Procedures & making animations
A procedure, sometimes called a custom block or sub-procedure, is a named group of instructions. You can call it again instead of copying the whole block of code.
Why use procedures?
✓ Less repeated code
✓ Easier to read and test
✓ Fix an error in one place
✓ Break a large animation into manageable tasks
Animation vocabulary
Sprite: an object or character in a scene.
Costume: one appearance of a sprite.
Stage: the background area.
Frame: one image in a sequence.
define flapWing
    next costume
    wait 0.2 seconds

repeat 4 times
    flapWing
This is illustrative pseudocode. Repeatedly switching costumes with a short wait can make a sprite look as though it moves.


Unit 5 · Topic 9
9. Variables, calculations & IF statements
A variable stores a value that may change while a program runs, such as a score, a timer or the speed of a character.
Trace values in order
set points to 7
change points by 5
set double to points * 2
points starts at 7, becomes 12, then double becomes 24.
IF / ELSE decisions
set points to 12
if points >= 10 then
    say "Level up"
else
    say "Keep trying"
The test is true, so the first message appears.
ComparisonMeaningExample
>Greater than12 > 9 is true
<Less than5 < 3 is false
=Equal to (as a comparison)4 = 4 is true
≥Greater than or equal to10 ≥ 10 is true
To answer a longer tracing question, use a small table and update variables after each block. A variable changed earlier can affect which IF branch runs later.
Key difference: set score to 5 stores a value. A check such as score > 5 asks a true/false question. An IF runs one group of instructions only when its condition is true; an ELSE gives an alternative.

10. New exam-style practice challenges
Try these without opening the answers first. The figures, scripts and contexts are not taken from your school assessment.
Challenge 1 · An exterior turn is 18°. How many sides does the regular polygon have? [2 marks]
360° ÷ 18° = 20 sides. State the formula and the answer.
Challenge 2 · Continue 9, 14, 21, 30, 41 with two more numbers. [2 marks]
Gaps are +5, +7, +9, +11. Next +13 and +15, giving 54 and 69.
Challenge 3 · Describe an efficient algorithm for a regular nonagon. [2 marks]
Repeat nine times: move forward a fixed distance, then turn 40°.
Challenge 4 · An automated drone checks a dangerous cliff face. Give one reason to use a machine. [2 marks]
It can gather inspection information without requiring a person to stand in the dangerous location. Reason + explanation earns stronger credit.
Challenge 5 · An animation uses the same jump action in five scenes. Explain why a procedure helps. [2 marks]
The procedure can be called in each scene without copying all the jump instructions, and any change can be made once.
Challenge 6 · Trace the result: set speed to 4; set boost to 6; set result to speed × boost; if result > 20, change result by −3. [3 marks]
speed = 4; boost = 6; result = 24; the test 24 > 20 is true, so result ends as 21.
Revision routine: Name the rule, show the working, explain the effect of each instruction and check whether your answer matches the question.
