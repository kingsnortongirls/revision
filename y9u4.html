Revision notes

Everything you need to know

Based on the two lessons in your Photopea scheme of work. The notes also include a few useful design and saving tips for better-quality coursework.

Lesson 1 · Getting started in Photopea

Photopea is a browser-based image editor. Start at photopea.com. Choose New Project or open an existing picture.

  • Canvas: the picture you edit.
  • Toolbar: choose Brush, Spot Healing Brush, Clone Stamp and more.
  • Options bar: change the chosen tool’s settings.
  • Layers: keep different parts of the work separate.

Practise: Create a simple original illustration using different brush sizes, then work on a copy of a photograph for retouching.

Lesson 1 · Brush tool
🖌
Paint with a chosen colour
Tool settings: size, hardness and opacity.
  1. Select the Brush tool.
  2. Choose a foreground colour.
  3. Set a suitable brush size.
  4. Draw on the correct layer.
  5. Undo mistakes and adjust the settings.

Tip: A soft brush can produce gradual edges; a hard brush is suitable for sharper outlines.

Lesson 1 · Spot Healing Brush
✨
Remove small marks
The editor chooses nearby image content to fill the covered area.
  1. Zoom in on the unwanted spot.
  2. Choose Spot Healing Brush and a brush slightly larger than the mark.
  3. Paint over the spot and release.
  4. Inspect the background and undo if the result looks unnatural.

Important: This is particularly useful on simple backgrounds. A busy edge can be harder for the tool to repair convincingly.

Lesson 1 · Clone Stamp
🧽
Copy from one place to another
You choose the source of the pixels.
  1. Choose Clone Stamp.
  2. On a desktop, Alt-click a clean source that matches the target area.
  3. Brush over the unwanted object.
  4. Change the source as needed and check for repeating details.

Compare: Spot Healing works out suitable detail automatically; Clone Stamp follows the source you pick.

Lesson 2 · Text tool and typography
🔠
Make your message readable
Headlines, supporting information and layout.
  1. Select the Type/Text tool (T).
  2. Click to create a text layer and enter your wording.
  3. Choose an appropriate font, colour and size.
  4. Move the text so it has enough space.
  5. Check contrast against the background image.

Use a clear headline, smaller supporting information and consistent alignment. Avoid putting tiny text over a busy image.

Lesson 2 · Designing a successful poster

Work backwards from the audience and the purpose. A useful poster should answer What?, When?, Where? and sometimes What next?.

  • Start with a headline and a suitable, appropriately licensed image.
  • Remove distracting details only where appropriate.
  • Add and format text so it stands out.
  • Use a limited colour palette and check spelling.
  • Show a friend the poster at a small size to test readability.

Challenge: Explain why your selected images, colours, font and tool choices suit the intended audience.

Saving, exporting and responsible editing

Save as PSD to retain editable layers. Use File → Export As → PNG/JPG when you need an image to share. PNG is useful for sharp graphics and text; JPEG is often compact for photographs.

Keep your original photographs, use images with permission and never present misleading edited photographs as unaltered evidence.
