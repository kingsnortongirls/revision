Flashcard questions and answers

Select a question to reveal its answer. These cards can also be read if JavaScript is restricted by your phone or file viewer.

⌨️ A wildlife centre uses a touch display to let visitors choose an animal and then plays its call. Give one input and one output function of this system.

Touch detection is an input because the visitor selects an option; the screen and/or speaker provides output.

⌨️ A greenhouse computer receives the temperature from a sensor. Is the sensor providing input or output? Explain.

Input. The sensor sends a temperature reading into the computer for processing.

⌨️ Why can a tablet touchscreen be described as both an input and an output device?

It displays images and text (output) and detects taps or gestures (input).

⌨️ A ticket machine prints a receipt after a customer makes a choice. Identify the output device and the information it produces.

The printer is the output device; it produces the paper receipt or ticket.

⌨️ A person with sight loss uses speech recognition and a screen reader. Identify the input and output methods used.

Input: microphone receiving speech. Output: speakers or headphones reading information aloud.

🧹 A camera warns that its memory card needs formatting. What should the owner do before agreeing, and why?

Copy any needed photographs to another location first, because formatting can remove access to files already on the card.

🧹 What does formatting prepare a storage device to do?

It prepares the device to hold and organise files, usually by creating a file system.

🧹 A teacher changes a heading to bold and centres it. Is this the same kind of formatting as formatting a disk? Explain.

No. Text formatting changes the appearance of a document. Disk formatting prepares storage for saving files.

🧹 Why might an external drive need a suitable file system before it can be used by different computers?

The operating systems need to recognise the file system so they can read and write data on the drive.

🧹 A student accidentally formats a device instead of organising folders. Why is this different from simply creating a new folder?

Formatting can replace file-system information and make existing files inaccessible; making a folder just organises files.

🎛️ A museum wants to record and edit an audio guide. Suggest one input peripheral and one type of software it needs.

A microphone to capture narration and audio-editing software to cut or improve the recording.

🎛️ A design club wants to draw a digital badge by hand. Suggest a suitable input peripheral and application.

A graphics tablet or stylus, together with drawing or image-editing software.

🎛️ A theatre group wants to print a professionally laid-out programme. Name one useful application and one output peripheral.

Desktop publishing software for the layout and a printer for the finished programme.

🎛️ A gardener wants a computer to record soil moisture automatically and show trends. Identify the input hardware and a suitable application type.

A moisture sensor for input and spreadsheet or data-logging software to display readings and trends.

🎛️ A club wants to add subtitles and transitions to a short recorded film. What type of application should it use, and why?

Video-editing software, because it can arrange clips and add text/subtitles and transitions.

🧩 A scientist has hundreds of measurements and wants a chart that updates when figures change. Which application type is suitable?

Spreadsheet software, because it can calculate with data and create charts.

🧩 A community library needs to search thousands of books by author and title. Which application type would best suit this task?

Database software, because it stores structured records that can be searched and filtered.

🧩 A team needs to deliver a slideshow with speaker notes. What type of software should they choose?

Presentation software.

🧩 A pupil is building a simple control program for a model traffic light. Which software environment could help write and test the code?

An integrated development environment (IDE) or suitable programming editor.

🧩 A local history society is laying out a multi-page magazine with text flowing around images. Which application type is most appropriate?

Desktop publishing (DTP) software.

⚙️ Explain why a device driver is system software rather than application software.

A driver helps the operating system communicate with hardware; it supports the computer rather than directly completing an end-user task.

⚙️ A computer has backup software and a drawing app installed. Which is a system utility, and which is an application?

Backup software is a system utility; the drawing app is application software.

⚙️ Give one important job carried out by an operating system that a photo editor does not normally do.

The operating system manages hardware, memory, files and running programs; the photo editor edits images.

⚙️ Why does a computer need system software even when the owner has not opened any applications?

System software starts and manages the computer, its hardware and essential services.

⚙️ What distinguishes software used to produce a podcast from software that manages the computer’s storage?

Podcast software is an application for a user task; storage management software is a system utility.

🔌 Why must the instructions that begin a computer’s start-up process be stored in non-volatile memory?

They need to remain available when power is off, so the computer can start when switched on.

🔌 A computer checks its main hardware as soon as the power is switched on. What is this start-up check commonly called?

The power-on self-test (POST).

🔌 What is one difference between the BIOS or UEFI firmware and the operating system?

Firmware begins hardware initialisation and booting; the operating system then manages the computer for normal use.

🔌 A computer cannot find a bootable drive. At what general stage of starting up is the problem likely to have happened?

During firmware/boot selection, before the operating system has loaded successfully.

🔌 Why would start-up firmware be unsuitable if it were stored only in ordinary volatile RAM?

RAM loses its contents when power is removed, so the start-up instructions would not be there when the computer was switched on.

🛡️ Security software moves a suspicious file into quarantine. What does quarantine mean?

The file is isolated so that it cannot easily run or harm the system while it is checked or removed.

🛡️ Why should security software update its malware definitions regularly?

New threats appear. Updated definitions help the software recognise more recent malware.

🛡️ A scan reports malicious software on a laptop. Give two actions anti-malware software may take.

For example: block it, quarantine it, remove it, or alert the user. Any two.

🛡️ Why is having anti-virus software not a reason to open every unknown attachment?

Some threats may not be recognised; unsafe links or attachments can still lead to infection or scams.

🛡️ What is the difference between detecting malware and preventing malware from running?

Detection identifies a possible threat; prevention blocks or stops harmful activity before it can cause damage.

🔄 A developer discovers a weakness that might allow attackers into an app. How can automatic updating reduce the risk?

It can install a security patch that fixes the weakness without relying on the user to find the update manually.

🔄 Why might a school schedule device updates outside lesson times?

To reduce disruption from downloads, restarts or temporary unavailability during learning.

🔄 Give two reasons to keep an operating system updated apart from adding new features.

Fix security vulnerabilities; fix errors/bugs; improve compatibility, stability or performance. Any two.

🔄 Why can a computer sometimes need restarting after installing an update?

Some system files or components cannot be fully replaced while in use; restarting loads the updated versions.

🔄 What is one risk of repeatedly postponing security updates?

Known weaknesses may remain open to attackers or malware for longer.

🧠 A computer game needs to calculate where moving objects should appear. Which main component carries out these instructions?

The central processing unit (CPU).

🧠 Describe the three stages of the CPU’s basic instruction cycle.

Fetch an instruction, decode what it means, then execute the instruction.

🧠 How do the CPU and RAM work together when a program is running?

RAM holds the instructions and data currently needed; the CPU fetches, processes and executes instructions using them.

🧠 Why is the CPU not normally the best place to keep family photographs permanently?

Its job is processing instructions, not long-term file storage; photographs are stored on secondary storage such as an SSD.

🧠 A weather sensor sends a reading to a computer. What could the CPU do with that reading?

Process or compare the value with a rule, then decide whether to trigger an output such as a warning.

💽 A laptop owner wants faster start-up and no moving parts in the internal drive. Which storage technology is suitable, and why?

A solid-state drive (SSD); it uses flash memory with no moving parts and typically offers fast access.

💽 Why might a company keep large archive files on hard disk drives rather than only on small memory cards?

Hard disk drives can provide high capacity at a lower cost per gigabyte for large data sets.

💽 A school stores important work on its main drive. Give one reason it should also keep a separate backup.

A backup can restore files if the main drive fails, is damaged, is stolen or files are deleted.

💽 What is one reason to choose an external solid-state drive for carrying project files between locations?

It is portable and can be fast and resistant to damage from movement because it has no spinning disk.

💽 What feature distinguishes secondary storage from ordinary RAM when a computer is switched off?

Secondary storage is non-volatile: saved files are retained without power.

🗂️ A laptop becomes slow when dozens of browser tabs and apps are running. Why might adding more RAM help?

More RAM can hold more active data and programs, reducing the need to swap data to slower secondary storage.

🗂️ A pupil has not saved changes before a power cut. Explain why work held only in RAM may be lost.

RAM is volatile and loses its contents without power; unsaved changes might not have been written to secondary storage.

🗂️ While a video-editing program is open, give two examples of information that might be held in RAM.

The running program’s instructions, video clips being worked on, effects data or unsaved edits. Any two.

🗂️ Why does opening a large game use RAM even though the game is installed on an SSD?

The game is stored on the SSD but active instructions and data are loaded into RAM so the CPU can use them.

🗂️ Is RAM usually a suitable place to keep a finished homework file for several months? Explain.

No. It is temporary, volatile memory; the file needs to be saved to non-volatile secondary storage.

📀 Classify each medium by technology: Blu-ray disc, internal SSD and traditional hard disk.

Blu-ray: optical; SSD: flash; traditional hard disk: magnetic.

📀 What physical method is used to read data from an optical disc?

A laser reads the pattern recorded on the disc.

📀 Why is an SSD described as flash storage rather than magnetic storage?

It stores information electronically in non-volatile memory cells, not by magnetising a spinning platter.

📀 A museum has decades of data on computer tape cartridges. What broad storage technology does this use?

Magnetic storage.

📀 Give an example of flash storage other than a solid-state drive.

A USB flash drive or an SD/microSD memory card.

⚖️ Someone guesses another person’s password and enters their private online account without permission. Which UK law is relevant?

The Computer Misuse Act 1990, because it addresses unauthorised access to computer material.

⚖️ A website copies an illustrator’s drawing and publishes it without permission. Which area of UK law is most relevant?

Copyright law, including the Copyright, Designs and Patents Act 1988.

⚖️ A fitness app shares customers’ phone numbers with advertisers without an appropriate lawful basis. Which UK data rules matter?

Data protection law, including the Data Protection Act 2018 and UK GDPR.

⚖️ Give a different example of behaviour covered by each of these: computer misuse, copyright and data protection.

Computer misuse: accessing an account without permission. Copyright: copying someone’s creative work without permission. Data protection: mishandling personal information.

⚖️ Why should a club limit access to its membership records to authorised staff?

To help prevent personal information being seen, copied or misused by people who do not need it.

🔓 A community workshop is choosing between a free-to-use open-source OS and a paid proprietary OS. State one possible saving and one trade-off with open source.

Possible saving: lower licence cost. Trade-off: a particular program or specialist hardware might be less compatible or need extra support.

🔓 What does open source mean when describing an operating system?

Its source code is available under a licence that allows people to inspect, use, modify and share it under the licence terms.

🔓 Why might a company prefer a proprietary operating system even when it costs more?

It may offer familiar software, vendor support, managed services or compatibility with required applications.

🔓 Does “open source” automatically mean an operating system has no costs at all? Explain.

No. The software may have no licence fee, but setup, training, maintenance and support can still cost money.

🔓 An engineering firm needs a specialised design program that only works on one OS. Why might compatibility outweigh purchase price?

If the required application will not run, the cheaper OS may not let staff do their work; compatibility is essential.

🌱 A household replaces a working laptop every year. Give two environmental impacts of this habit.

For example: more electronic waste, greater use of raw materials, manufacturing energy and transport emissions. Any two.

🌱 A school has old computers that still work. Suggest one option that could reduce waste before recycling them.

Repair, upgrade, redeploy or donate suitable computers after securely removing personal data.

🌱 Why should broken electronic equipment not usually be placed in ordinary household rubbish?

It can contain hazardous materials and valuable components that need specialist recycling or treatment.

🌱 A computer is left running all night when not needed. Identify one environmental cost and one improvement.

It uses unnecessary electricity; switch it off or use sensible sleep/power-saving settings.

🌱 A repairable laptop has a failing battery. Explain one possible environmental advantage of replacing the battery instead of the whole laptop.

It extends the device’s useful life, reducing the need for a new machine and the raw materials and waste associated with replacement.

🤖 A leisure centre introduces automatic entrance gates. Explain one possible benefit for the organisation and one concern for visitors.

Benefit: faster entry or lower routine staffing demands. Concern: barriers for people needing help or problems if technology fails.

🤖 A restaurant uses touchscreens for taking orders. Explain one possible change to the work staff carry out.

Staff may spend less time recording orders but more time helping customers, preparing food or solving problems; some roles may change.

🤖 A library uses automatic book-return machines. Give a benefit and a drawback of relying on them.

Benefit: quicker returns or longer service availability. Drawback: faults, accessibility issues or reduced face-to-face assistance.

🤖 Why should a business consider both customers and employees before introducing automated systems?

The technology may improve efficiency but can affect accessibility, job roles, training needs and people who need human support.

TOPIC 01 OF 16

Input and output devices

An input sends data into a computer. An output presents information or takes an action from a computer.

  • Input: keyboard, mouse, microphone, scanner, temperature sensor and camera.
  • Output: monitor, speakers, headphones, printer, projector and motor.
  • Both: a touchscreen shows information and detects touch.
Exam tip

Give the device and say whether data is entering or leaving the computer. A device can have both functions.

🧹

TOPIC 02 OF 16

Formatting storage

Disk formatting prepares a storage device with a file system so files can be stored and organised.

  • Formatting is not the same as making a folder or changing a document’s font.
  • It can make existing files inaccessible. Back up important files first.
  • Some devices need a compatible file system to work with a computer or camera.
Exam tip

If a question says “format the drive”, discuss the file system and the danger to existing files, not bold or italic text.

TOPIC 05 OF 16

System and application software

System software runs, controls and maintains the computer. Application software helps the user do a particular task.

System

Operating system, device drivers, backup utility, disk management and anti-malware utility.

Application

Web browser, image editor, presentation program, word processor and computer game.

Exam tip

Explain the purpose, not just the name. For example, backup utilities protect stored files.

🔌

TOPIC 06 OF 16

ROM, firmware and BIOS

ROM means read-only memory. Unlike RAM, it retains information without power. Start-up firmware is stored in non-volatile memory.

Power on›BIOS / UEFI firmware›Hardware checks›Find boot drive›Load operating system
  • BIOS stands for Basic Input/Output System.
  • Firmware helps initialise hardware and find the software needed to start the computer.
  • The power-on self-test (POST) checks important hardware during start-up.
  • Many modern PCs use UEFI rather than traditional BIOS, but the basic start-up idea is similar.
Exam tip

Keep BIOS/UEFI separate from the operating system. Firmware runs first; the operating system takes over after booting.

🛡️

TOPIC 07 OF 16

Anti-virus and malware protection

Malware is harmful software. Anti-virus / anti-malware tools help detect, block, quarantine and remove threats.

  • Scan: check files or processes for signs of malware.
  • Quarantine: isolate a suspicious file to stop it running.
  • Definitions / detection rules: keep these up to date to identify newer threats.
  • Protection is not perfect. Still avoid suspicious downloads, unsafe attachments and untrusted links.
Exam tip

A strong two-mark answer often says what it does and how that protects the computer.

🔄

TOPIC 08 OF 16

Automatic software updates

An automatic update downloads and installs software changes without the user having to search for every update.

  • Security patches fix vulnerabilities attackers could exploit.
  • Updates can also repair bugs and improve stability or compatibility.
  • Some updates require a restart, so schools may schedule them outside lessons.
  • Putting off important security updates can leave known weaknesses uncorrected.
Exam tip

To explain a benefit, link the update to the result: “installs a security fix, reducing the chance of an attack”.

🧠

TOPIC 09 OF 16

CPU and processing

The central processing unit (CPU) follows instructions and processes data.

Fetch›Decode›Execute
  • Fetch: get the next instruction from memory.
  • Decode: work out what it means.
  • Execute: perform the required operation.
  • The CPU works with RAM; it is not the same as long-term file storage.
Exam tip

If asked for the CPU’s job, use words such as “process”, “instructions” and “data”.

TOPIC 10 OF 16

Secondary storage choices

Secondary storage keeps files and applications even when the power is off. It is non-volatile.

DeviceUseful feature
HDDLarge, often inexpensive capacity; moving magnetic disk
SSDFast access, no moving disk; flash memory
USB drive / memory cardSmall and portable; flash memory
Optical discRemovable, laser-read medium
Magnetic tapeUseful for some large archives and backups

Keep a separate backup for important data, not just another folder on the same disk.

Exam tip

Choose a device according to the scenario: speed, capacity, portability, price and durability.

🗂️

TOPIC 11 OF 16

RAM and primary memory

Random access memory (RAM) temporarily holds instructions and data that programs are using now.

RAM (primary memory)

Fast, temporary and volatile. Loses its contents when power is removed.

SSD / HDD (secondary storage)

Holds saved files and software for the longer term, including when power is off.

Opening a saved app loads parts of it into RAM so the CPU can work with it.

Exam tip

Avoid saying RAM is where all files are permanently saved. Think “currently in use”.

📀

TOPIC 12 OF 16

Optical, magnetic and flash storage

Storage devices use different physical technologies.

💿Optical

Laser reads a disc. Examples: CD, DVD, Blu-ray.

🧲Magnetic

Magnetised material stores data. Examples: HDD, tape.

⚡Flash

Electronic non-volatile memory. Examples: SSD, USB drive, SD card.

Exam tip

Learn the technology as well as a device name. Different devices can share the same technology.

⚖️

TOPIC 13 OF 16

Computer laws and digital rights

Three main areas of UK computer law appear in this unit.

Computer Misuse Act 1990

Deals with unauthorised access and other computer misuse.

Copyright, Designs and Patents Act 1988

Protects creators’ original works and rights against unauthorised copying.

Data Protection Act 2018 and UK GDPR

Rules about handling personal information lawfully, fairly and securely.

Important: Your older OCR paper names the Data Protection Act 1998, which has since been replaced. Learn the purpose of the law for the assessment, and recognise the current 2018 Act and UK GDPR.

Exam tip

Spot the difference: hacking/unauthorised access = computer misuse; copying creative work = copyright; personal records = data protection.

🔓

TOPIC 14 OF 16

Open-source and proprietary operating systems

An open-source operating system makes its source code available under an open-source licence. Proprietary systems are controlled under the owner’s licence terms.

Open source

Possible benefits: no licence fee, customisation, community support. Possible drawback: compatibility and specialist support vary.

Proprietary

Possible benefits: familiar programs, vendor support, compatibility. Possible drawback: licence cost or less control over source code.

Exam tip

For “explain one advantage”, write the advantage and why it would help that organisation.

TOPIC 15 OF 16

Environmental impacts of computing

Computers affect the environment when they are made, used and disposed of.

1Manufacture

Raw materials, water and energy are needed.

2Use

Electricity is consumed during operation.

3Disposal

E-waste may contain hazardous and valuable materials.

Reduce impact: repair, upgrade, reuse, donate and recycle through appropriate schemes. Remove personal data securely before disposal or donation.

Exam tip

Explain the environmental link: for example, repairing a laptop reduces waste and the demand for new raw materials.

TOPIC 16 OF 16

Technology in everyday work

The second attached paper also tests the benefits and drawbacks of replacing manual tasks with automated systems.

Possible benefits

Faster routine tasks, consistent service, lower running costs, or longer opening times.

Possible drawbacks

Faults, accessibility barriers, less face-to-face help, staff retraining or changes to jobs.

When evaluating a new system, consider the organisation, the workers and the people who use it.

Exam tip

Do not only list a benefit. Say who benefits and why, or who may experience the drawback.
