What to notice

PC normally increments during fetch; CIR contains the current instruction, while MAR and MDR can be reused to fetch operands. A taken branch could overwrite PC during execute. This is a simplified teaching model.

Instruction pipelining visualiser

See five or more independent instructions pass through Fetch (F), Decode (D), and Execute (E). Each stage takes one idealised clock cycle.

A stall penalty is added to the illustrative total. Actual hazard timing depends on the instruction mix and processor design.

CPU and parallelisation explorer

Model the theoretical benefit from multiple cores. This is a simple Amdahl's law illustration, not a benchmark of real processors.

Clock speed

More cycles per second can help comparable processors, but instructions per cycle, memory stalls, power and heat also matter.

Cache

Cache hits avoid slower RAM accesses. Capacity alone cannot predict hit rate for all workloads.

Address bus and word-size calculator

For this model, one address points to a complete word. Explore the difference between number of addresses and bytes of capacity.

In an ordinary byte-addressable model, each address points to one byte irrespective of processor word size. Check what each address selects before calculating capacity.
