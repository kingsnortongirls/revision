KNOW THE PEOPLE

1. Computing pioneers

Charles Babbage

A nineteenth-century mathematician and inventor who designed the Difference Engine, intended to automate mathematical tables, and later proposed the more ambitious Analytical Engine.

George Boole

Developed an algebra of logic based on true and false. This idea helps explain how computers can use simple binary decisions to carry out complicated tasks.

Alan Turing

Helped develop the theory of computation and worked at Bletchley Park during the Second World War as part of the teams involved in breaking encrypted messages.

Sir Tim Berners-Lee

Proposed the World Wide Web in 1989 while working at CERN. The Web made it easier to find and share linked information over the Internet.

Remember: these developments did not happen in isolation. Each built on other ideas, people and technologies.

LESSON 1

2. Encryption and codebreaking

A cipher is a method of changing a message. Encryption turns a message into an encoded form; decryption reverses it. A key tells you which transformation to use.

Pigpen

Each letter is represented by a shape from a grid or an X. A dot identifies the second group of symbols. For practice, use the complete key in the Ciphers tab.

Example word: STAR. The visual symbols change, but the order of the letters stays the same.

Caesar

Move each letter by an agreed number of places. Example: with a shift right by 4, A → E, B → F and W → A. To decode, shift left by 4.

Uncoded
MOON
Right shift 4 ↓
QSSR
Important: A Caesar cipher is a teaching example, not a secure way to protect modern personal data. Keep your key and direction consistent.
LESSON 2

3. Internet versus World Wide Web

Internet

The worldwide system of connected networks and devices. It provides the infrastructure through which information travels.

Examples of services: email, web browsing, messaging and online games.

World Wide Web

Linked pages and other resources accessed using web browsers. The Web uses the Internet; it is not another name for the Internet.

Key words: website, web page, hyperlink, hypertext, browser.

TermRemember this

LESSON 2

4. Your first web page with HTML

HTML describes the structure of content. The browser reads the tags and displays headings, paragraphs, links and images.

<!doctype html>
<html lang="en-GB">
<head>
  <title>Ocean facts</title>
</head>
<body>
  <h1>Amazing oceans</h1>
  <p>The ocean covers much of Earth.</p>
  <a href="https://example.org">Find out more</a>
</body>
</html>

Common HTML tags

<h1> main heading; <p> paragraph; <a> hyperlink; <img> image. Closing tags commonly start with a slash.

CSS

CSS changes the appearance of a page, for example the background, colours, fonts, alignment and spacing. HTML and CSS work together.

LESSON 3

5. Boolean logic and truth tables

A logic gate takes one or more binary inputs and produces a binary output. We use 0 for false and 1 for true.

AND

Output 1 only if both inputs are 1.

OR

Output 1 if at least one input is 1.

NOT

Reverse the input: 0 becomes 1 and 1 becomes 0.

A common mistake

OR also produces 1 when both inputs are 1. It does not mean “one or the other, but not both”.

The small circle on a gate symbol means NOT (inversion).

LESSON 3

6. Solving multi-gate circuits

Step 1: Find the initial input numbers. Step 2: Calculate the output of the first gate. Step 3: Use that result as an input to the next gate.

Worked example: NOT 0 = 1, then 1 AND 1 = 1. The final answer is Q = 1. This is a different circuit and set of values from the assessment.
LESSON 4

7. Babbage and problem-solving

Algorithms & decomposition

An algorithm is an ordered set of unambiguous instructions. Decomposition means breaking a big problem into smaller pieces.

Test solutions on small examples and check they obey the rules.

Tower of Hanoi idea

Move a stack of discs between pegs, moving only one disc at a time and never putting a larger disc on a smaller one. It is a classic way to practise planning and logical steps.

LESSON 4

8. Bubble sort, one step at a time

To sort ascending, compare neighbouring values. If the left is greater than the right, swap them. Move to the next pair. At the end of a full pass, the largest unsorted value is in its final position.

Start with

7251

Compare 7 and 2: swap. Compare 7 and 5: swap. Compare 7 and 1: swap.

After one pass

2517

The list is not fully sorted, but the biggest value is at the end. More passes are needed.

Quick self-check

Explain the difference between AND and OR.

AND needs both inputs to be 1. OR needs at least one input to be 1.

What changes if you decode a Caesar message using the wrong shift?

It produces different letters, usually a message that makes no sense.

Why does one bubble-sort pass not always finish the job?

It moves the largest item to the right, but smaller items may still be in the wrong order.

Is the Internet the same as a web browser?

No. The Internet is a network infrastructure; a browser is software that accesses web pages through it.
