LESSON 1
1. Getting started and printing
Python is a text-based programming language. Code is usually run from top to bottom. IDLE is a simple environment for writing and running Python programmes.
print("Welcome to the coding club!")
print(4 + 5)
print("4 + 5")
The first line prints a message. The second prints 9. The third prints the literal text 4 + 5, because it is in quotes.
Strings
A string is text surrounded by quotation marks: "Birmingham" or 'Welcome'.
Multiple lines
The escape sequence \n begins a new line inside a string.
print("One\nTwo")


LESSONS 1–2
2. Variables and input
A variable stores a value under a name. = assigns a value. input() lets someone enter text.
city = input("Which city? ")
print("You chose", city)
level = 2
level = level + 1
print(level)
The final line displays 3. Values can change as the programme runs.
Common mistake: print("level") displays the word level, but print(level) displays the value held in that variable.


LESSON 2
3. Comments and readable code
A comment explains a programme to other people and to your future self. Python ignores comments starting with #. For longer comments, put # at the start of each line.
# Ask the user about their hobby
# and remember the answer
hobby = input("Favourite hobby: ")
print("Hobby:", hobby)
Use meaningful variable names, save work regularly and put each step on its own line. Indentation will be particularly important for selection.


LESSON 3
4. Data types and casting
TypeMeaningExample
String strText"Purple"
Integer intWhole number17
Float floatDecimal number3.75
input() always returns a string. To do maths with an entered number, convert it first. This is called casting.
minutes = int(input("Minutes: "))
seconds = minutes * 60
print("Seconds:", seconds)
Common mistake: "6" + "2" produces "62", whereas 6 + 2 produces 8.


LESSON 3
5. Arithmetic and order
OperatorMeaningExample
+Add8 + 3 is 11
-Subtract8 - 3 is 5
*Multiply8 * 3 is 24
/Divide8 / 4 is 2.0
Python follows the usual order of operations: brackets, multiplication/division and then addition/subtraction at this level.
print(4 + 2 * 5)    # 14
print((4 + 2) * 5)  # 30


LESSON 4
6. Selection with IF, ELIF and ELSE
Selection lets a programme choose a path. Conditions can compare values using == (equal to), >, <, >=, <= or !=.
stamps = int(input("How many stamps? "))
if stamps >= 12:
    print("Large collection")
elif stamps >= 5:
    print("Growing collection")
else:
    print("Just getting started")
if
Checks the first condition.
elif
Checks a further condition if earlier ones were false.
else
Runs when no earlier branch matched.
Indentation
Indent each branch's instructions by four spaces. A colon ends each if, elif and else line.
Remember: = assigns a value. == checks whether two values are equal.


ALL LESSONS
7. Testing, syntax and logic errors
Syntax error
A Python rule has been broken, for example a missing quote, bracket, colon or required indentation.
print("Hello"
Logic error
The code runs but answers incorrectly, for example adding a fee when you meant to subtract it.
price = 25
sale_discount = 5
final = price + sale_discount
Debugging means finding and fixing problems. A dry run means tracing each line manually, recording variable values and outputs.
Try these quick checks
Why does input() sometimes cause unexpected addition?
input() returns strings, so + can join the text instead of adding numbers. Convert using int() or float().
What is the difference between an assignment and a comparison?
= stores a value; == checks whether two values match.
Why does the code inside an if block need indentation?
Python uses indentation to identify which statements belong to that branch.
Why would you try at least two test values?
To see whether different branches and inputs produce the expected results.
