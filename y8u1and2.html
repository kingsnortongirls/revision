UNIT 1 · OPERATING SYSTEMS

1. GUI and WIMP

GUI stands for Graphical User Interface. This means using a computer through things you can see and select.

▣

W = Windows

Areas where programs and files appear. You can open and move windows.

▦

I = Icons

Small pictures you select to open apps, files or actions.

☷

M = Menus

Lists of choices, such as Save, Print or Settings.

➤

P = Pointer

The on-screen arrow controlled by a mouse or trackpad.

Remember: A GUI is not an operating system. Windows and macOS are examples of operating systems that provide a GUI.
UNIT 1 · OPERATING SYSTEMS

2. Operating systems

An operating system (OS) manages computer hardware and software, helps you use files and lets you run applications.

DeviceSuitable operating system
Windows desktop/laptopWindows
Apple MacBook or iMacmacOS
Many desktop/laptop computersLinux
Many non-Apple phones/tabletsAndroid
Apple iPhoneiOS
Apple iPadiPadOS

Don't mix these up: An operating system runs the computer. An application is software you use for a task, such as a web browser or word processor.

UNIT 1 · OPERATING SYSTEMS

3. Desktops, laptops and choosing the right device

🖥️

Desktop computer

Usually stays on a desk. May be easier to upgrade or repair and can offer strong performance.

💻

Laptop computer

Portable, with a built-in display, keyboard and rechargeable battery.

How to earn both marks in an 'explain' answer

Point: A travelling photographer could use a laptop.
Reason: It is portable, so they can edit photographs at different locations.

Look for clues in a scenario: Does someone work in different places? Need long battery life? Need a large display or lots of processing power? Do not choose a device just because it is popular.

UNIT 2 · THE COMMAND LINE

4. File management

File management is keeping files and folders organised. The main tasks are:

Create / name

Make a new file or folder and give it a helpful name.

Copy

Make an extra copy without removing the original.

Move

Put a file in a different location.

Rename / delete

Change a name or remove a file you no longer need.

Key word: A directory is another word for a folder.
UNIT 2 · THE COMMAND LINE

5. Recognising file extensions

A file extension is the part after the final full stop in a filename. It gives a clue about the file type.

Example filenameExtensionType
newsletter.docx.docxWord processing document
assembly.pptx.pptxPresentation
costs.xlsx.xlsxSpreadsheet
installer.exe.exeWindows executable program
ideas.txt.txtPlain text
guide.pdf.pdfPDF document

Remember: The same file type can have other extensions, but these are useful examples for your revision.

UNIT 2 · THE COMMAND LINE

6. GUI versus command-line interface

🖱️

GUI

Uses visual controls. Advantage: Beginners can often recognise buttons and icons more easily.

⌨️

CLI

Uses typed commands. Advantage: Experienced users can repeat or automate tasks quickly.

A command-line interface (CLI) is a text-based way of giving instructions to a computer. You type commands into a terminal or Command Prompt.

Two-mark technique: Include the advantage and explain why it helps. For example, 'A GUI uses recognisable icons, so a new user may find it easier to locate the function they need.'

7. Windows Command Prompt commands

The assessment uses commands in the style of Windows CMD. Practise writing these without looking:

Make a directory called Tripsmd Trips

Exam tip: Replace the example names with the filenames and folders you are given. Look for the .txt extension and spaces between parts of a command. These are Windows commands, not instructions for every type of terminal.
Check your knowledge

8. New exam-style practice

Cover the answers and attempt each one. These questions have new examples, not the ones in the supplied examination paper.

1. A learner taps a small picture to open a program. Which part of WIMP is this?

Icon. It is a small picture representing an app, file or action.

2. Name two operating systems used on smartphones or tablets.

For example, Android and iOS (or iPadOS for iPads).

3. A sports coach works in different schools. Suggest a computer and explain why. (2 marks)

Laptop because it is portable, so they can update documents at different schools. A tablet with a suitable explanation is also possible.

4. Which file extension would suit a presentation file?

.pptx

5. State four file management tasks.

Any four of: create, rename, copy, move, delete, organise files or folders.

6. Explain one advantage of a command line over a GUI. (2 marks)

It can repeat tasks using commands or scripts, so a technician can work faster when carrying out the same job many times.

7. In Windows CMD, write a command to make a folder called Geography.

md Geography

8. In Windows CMD, write a command to move list.txt to an existing folder called Homework.

move list.txt Homework
